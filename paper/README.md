# Aligned but Apart — TMLR manuscript source

Build (needs a LaTeX toolchain; we used `tectonic`, which auto-fetches packages):

    tectonic -X compile main.tex        # -> main.pdf (12 pages)

or with a standard TeX install:

    pdflatex main && bibtex main && pdflatex main && pdflatex main

Layout:
    main.tex            title, abstract, intro, contributions; \input's the sections
    sections/*.tex      related, method, results, discussion, appendix_surgery
    references.bib      14 verified entries (all first-author surnames + arXiv IDs checked)
    figures/*.pdf       fig0 (schematic) + fig1–fig6, regenerated by ../figures/make_figures.py
    tmlr.sty/.bst, fancyhdr.sty   TMLR style files (from JmlrOrg/tmlr-style-file)
