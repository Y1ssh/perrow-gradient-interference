# Aligned but Apart -- manuscript source

The build lives under `venues/`, one folder per venue. See
[`venues/README.md`](venues/README.md) for the build commands and the three
layout constraints, and [`../docs/VENUE_MAP.md`](../docs/VENUE_MAP.md) for what
is venue-specific versus venue-independent.

    cd venues/zenodo && tectonic -X compile main.tex --outdir . --keep-intermediates

Layout:

    venues/zenodo/   preprint build: real author block, no review furniture
    venues/tmlr/     double-blind build: review header, anonymous authors
    sections/*.tex   shared content, stored once and reached with ../../
    figures/*.pdf    regenerated by ../figures/make_figures.py and make_schematic.py
    references.bib   shared bibliography

Both venues compile to 28 pages with zero undefined references. Style files
(`tmlr.sty`, `tmlr.bst`, `fancyhdr.sty`) sit inside each venue folder because
LaTeX resolves them relative to the file being compiled.
